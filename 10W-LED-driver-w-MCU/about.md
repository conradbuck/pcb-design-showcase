# 10W RGB LED custom driver circuitry

This PCB contains all of the necessary control and driver circuitry to manipulate a high power RGB LED with arduino code. I used a PT4115 driver because I saw several other designs for controlling this type of LED using that chip. 

All of these other designs were closed source as people were selling the PCBs online. I wanted to use this driver in my own project because I had seen other people use it and it worked for them. I collected a gallery of images from various shop pages with this circuit implemented. I reverse engineering the wiring of the chip from the images on my computer alone and then implemented my paper schematic in KiCAD. I had this design assembled and it worked first try.
